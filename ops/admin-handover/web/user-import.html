3. 交付初始密码

初始密码只保留在当前页面内存中。请在关闭或刷新前下载，并逐人分发。交付表含密码，请妥善保存。

管理员重置密码

核实本人身份后重置。操作会结束该用户全部旧登录会话，保留课程记录和双重验证设置；不发送邮件。

新密码只在当前页面内存中保留，请下载后单独交给本人。自己的密码请在账号设置中修改。

仅限已授权的组织管理员使用。账号交付表请妥善保管。
